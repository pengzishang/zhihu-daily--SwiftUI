# 日报首页三方案 HTML 设计稿

## 目标

为“碎片时间快速扫一遍热点”的读者，制作三套可直接在浏览器打开的首页方案。三套方案都保留 DailyReader 的“今日刊”设计语言，不接入网络、不修改 SwiftUI 生产代码、不改变内容排序或推荐逻辑。

## 已确认的设计判断

- 核心任务：快速扫完今天有哪些内容。
- 核心读者：碎片时间快速扫一遍热点的人。
- 气质：精致、克制的数字日报。
- 共同语言：暖纸、浓墨、宋体结构文字、靛蓝交互强调、朱砂“今日”章记、髮丝线；以 [docs/design/design-system.md](../../design/design-system.md) 为视觉契约。
- 展示载体：一个独立 HTML 设计稿，页面中切换三套方案；不使用伪浏览器栏或伪手机边框。

## 三套方案

### A · 今日目录（推荐）

紧凑日期刊头、三条“先看”标题和连续文章目录。每篇只保留序号、标题、可选分类与已读状态；图片、摘要、互动指标让位于标题扫描。它是 Index-First 结构，最适合快速判断“今天有什么”。

### B · 头版 + 全览

以一张低高度的“今日头版”建立编辑判断，下面立即进入完整目录。它保留一个清晰的内容锚点，仍用目录完成全量扫读；相比 A，多一点刊物感，少一点首屏效率。

### C · 主题分版

先按主题呈现数个精简版面，再提供完整目录。它让用户按语义快速发现内容，适合已有兴趣偏好的读者；真实产品实现前需验证分类结果的稳定性和加载时机。

## 交互与响应式

- 方案切换使用语义化按钮，不依赖 URL 或网络。
- 浅色、深色可切换；`localStorage` 仅保存本地预览偏好。
- 三套内容在 320px、375px、414px、768px 宽度下无横向滚动；按钮保持单行和可见焦点。
- 仅使用 `opacity` 与 `transform` 表达方案切换，且尊重 `prefers-reduced-motion`。

## 非目标

- 不作为 SwiftUI 首页的实现规格，也不修改任何生产视图、数据模型或测试。
- 不添加虚构热度、阅读量、评价、人物或图片素材。
- 不对用户当前的首页密度功能作取代性承诺。
