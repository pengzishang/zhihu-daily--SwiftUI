# 文章列表左滑手势冲突修复 — 完成概览

## 问题
在文章列表（`HomeView`）中，对某一行**左滑**（触发"不感兴趣"隐藏）后松手，会**误触进入文章详情**，属于手势冲突。

## 根因
`HomeView.swift` 的私有视图 `SwipeToHideContainer` 把 `DragGesture` 通过
`.simultaneousGesture` 挂在 `NavigationLink` 的 `content` 上。`simultaneousGesture`
与 `NavigationLink` 的点击识别**并发执行**——一次"左滑并松手"既被拖拽识别，又满足了
`NavigationLink` 的点击命中，于是导航被触发，进入文章。

## 修复（已提交 27dc0e0）
1. 新增状态 `@State private var dragging: Bool = false`。
2. 把拖拽手势从 `.simultaneousGesture(content)` 改为 `.highPriorityGesture`
   挂在外层容器（`.clipped()` 之后），优先拦截水平滑动。
3. 给 `content` 加 `.allowsHitTesting(!dragging)`：滑动过程中（`dragging == true`）
   禁用链接点击，松手（`onEnded` 置回 `false`）后恢复。

**行为结果**
- 左滑：拖拽手势优先，期间链接不可点 → 不会进入文章。
- 普通点击（无拖拽）：`dragging` 始终为 `false`，链接正常命中 → 正常进入文章。
