- 修复我的页收藏/已读列表不渲染（提交 `d2b8be0`，version/2.1）：子自行定位根因——`9eba9c6` 把收藏/已读 `List` 套进 `ScrollView>VStack`，SwiftUI 在滚动容器内算不出 `List` 高度导致列表行不渲染（收藏/已读加载不出来）。修复：移除外层 ScrollView/VStack，新增 `topSectionSection`（透明背景/无分隔线/无 inset）作为 `favoritesList`/`readList` 的首个 Section，单 List 自身滚动；去掉 `.scrollDisabled(true)`；齿轮仍为普通 Button + 隐藏 NavigationLink 入口（不误触跳设置）；保留 `me.favorites.list`/`me.read.list` 标识满足 UI 测试；整页仍可滚动（头部随列表滚动）。**经验教训**：SwiftUI 中切勿把 `List` 放进 `ScrollView`/`VStack` 这类需要确定子视图高度的容器，否则 List 高度坍塌、内容不显示；要让整页滚动就用单个 `List` 承载全部内容（顶部区块作为首个 Section）。
